# 漫画管理器

一个自用的本地漫画管理 / 阅读工具。技术栈：**Electron + React + TypeScript + SQLite**，
所有数据都在本地，不联网、不上传。

## 支持格式

| 格式 | 说明 |
| --- | --- |
| 文件夹 | 一堆散装图片，按自然顺序排序 |
| `cbz` / `zip` | 压缩包，内部图片按自然顺序排序 |
| `epub` | 读取包内图片 |
| `mobi` / `azw3` / `azw` | 解析 PalmDB 容器，按 record 顺序抽图 |
| `pdf` | 仅登记（暂不渲染） |

## 功能

- **漫画库**：封面网格、拼音搜索（全拼 + 首字母）、按标签筛选
- **系列详情**：章节列表与进度、标签管理
- **阅读器**：翻页 / 滚动模式、缩放（适应窗口 / 宽度 / 高度 / 原始）、
  左右翻页方向、全屏、上一话 / 下一话、预加载下一页、
  单页收藏与漫画收藏
- **图片墙**：整话缩略图一览，快速跳页
- **标签**：自定义标签、按标签归类
- **主题**：暗夜黑 / 纯黑 OLED / 浅色 / 护眼绿 / 暗紫
- **封面策略**：跟随阅读进度，或固定第一卷

## 快捷键（阅读器）

| 按键 | 作用 |
| --- | --- |
| `←` `→` / 空格 | 翻页（到本章首尾会自动切换上一话 / 下一话） |
| `[` `]` | 上一话 / 下一话 |
| `+` `-` `0` | 放大 / 缩小 / 复位 |
| `Ctrl + 滚轮` | 缩放 |
| 双击 | 缩放复位 |
| `F` | 显示 / 隐藏工具栏 |
| `F11` | 全屏 |
| `ESC` | 返回 |

## 开发

```bash
npm install
npm run dev
```

## 打包

```bash
npm run dist      # NSIS 安装版 + 便携版，产物在 release/
npm run dist:dir  # 只生成解包目录，调试用
```

## 数据位置

所有数据都在 `%APPDATA%\MangaManager`：

```
manga.db      # 漫画 / 章节 / 收藏 / 标签
covers/       # 系列封面缓存（640px）
thumbs/       # 图片墙与收藏页缩略图缓存
```
